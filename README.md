# Flappy Bird

Jogo inspirado em Flappy Bird feito com HTML, CSS e JavaScript puro.

## Controles
- Toque na tela ou pressione Espaço para voar.
- Depois do Game Over, use **Jogar novamente**.
- O botão **Debug** ajuda a testar a física.

## Arquivos
- index.html
- style.css
- game.js
- manifest.webmanifest

## Publicação
O projeto está preparado para ser publicado pelo GitHub Pages e aberto pelo celular.
